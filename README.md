 # Reservation Manager Project
## 📄 Project Overview
This repository contains a reservation Manager Spring Boot application orchestrated with Docker Compose.
It helps to manage reservations and informed the hotel about guests needs and desires before their arrival.
---

## 📋 Prerequisites
 Before running the project, you need to following installed:
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) 
---
🚀 Getting Started
---
## 1. Clone the Repository

``` git clone [https://github.com/esmatoksoy/reservation-manager.git]``` 
--
## Build and Run with Docker Compose:

   ```docker-compose up --build```
---
## Management Commands:
### To run the application in detached mode, use:

```docker-compose up -d```
---
### To stop the application, use:
```docker-compose down```
---
### Access the Application
 Once the application is running, you can access it at:

```http://localhost:8080```
